# Обучение модели на 7 типов отходов — пошагово

**Что получится:** модель узнаёт 7 типов вместо 4 — стекло, металл, бумагу и картон, пластик **+ батарейки и электронику,
органику, прочее (несортируемое)** — и лучше работает на обычных фото, а не только на белом фоне.

**Что нужно:** аккаунт Google (для бесплатной видеокарты в Google Colab). **Время:** ~1,5 часа, из них ~1 час модель учится
сама — компьютер можно не трогать, но вкладку Colab не закрывайте.

Сайт уже готов к новой модели: тексты, советы и подсказка «батарейки — только в спецпункт» включатся сами,
как только в `assets/best.pt` окажется модель на 7 классов.

---

## Самый простой способ: обучение на сервере GitHub (без Colab)

Ничего ставить не нужно, компьютер можно выключить.

1. GitHub → репозиторий → **Actions** → слева **train-model** → **Run workflow** → **Run workflow**.
2. Подождать 3–5 часов: видеокарты на сервере GitHub нет, поэтому дольше, чем в Colab, зато без ручных шагов.
   Для публичного репозитория это бесплатно.
3. Готово, когда у запуска зелёная галочка. Вверху страницы запуска — **Annotations**: точность старой и новой
   модели по каждому классу и итог ✅ или ❌.
4. Результат — в ветке `claude/trained-model-<номер запуска>`, папка `trained/`: `models/new_best.pt` (модель),
   `models/compare.json` (сравнение), отчёты о датасете. Если итог ✅ — дальше «Шаг 5. Поставить модель на сайт».

Что делает сервер — то же, что ноутбук Colab ниже: скачивает TrashNet, RealWaste, TACO, электронику из Open Images,
собирает датасет, дообучает текущую модель сайта и сравнивает её со старой на одних и тех же тестовых фото.
Без Kaggle (батареек в обучении меньше) и без ваших фото из Supabase — их можно добавить через Colab.

## Шаг 0. Заранее: собирайте свои фото (лучше за неделю-две до обучения)
Фото, которые пользователи отправляют кнопкой **«Модель ошиблась»**, — самое ценное для обучения: это настоящие фото
с телефонов. Чтобы они не стирались на Streamlit Cloud, сайт кладёт их в приватное хранилище Supabase Storage.

1. Supabase → ваш проект. **id проекта** — в адресной строке браузера: `supabase.com/dashboard/project/<id проекта>`.
2. **Project Settings → API Keys → Secret keys**: создайте или откройте секретный ключ `sb_secret_…`
   (подойдёт и старый ключ `service_role` во вкладке Legacy). Он даёт полный доступ — никому не показывайте.
3. Streamlit Cloud → приложение → **⋮ → Settings → Secrets** — добавьте две строки и нажмите **Save changes**:
   ```toml
   SUPABASE_URL = "https://<id проекта>.supabase.co"
   SUPABASE_SERVICE_KEY = "sb_secret_…"
   ```
4. Проверка: на сайте распознайте фото → «Модель ошиблась» → выберите тип → «Отправить исправление».
   В Supabase → **Storage** появится приватный бакет `feedback` с папкой этого типа.

Особенно нужны фото **батареек** и **органики** — в открытых датасетах их мало. Просите одноклассников фотографировать
батарейки, телефоны, зарядки, очистки, листья и отправлять исправление с правильным типом.

## Шаг 1. Открыть ноутбук в Colab
Откройте ссылку (если изменения ещё не влиты в `main`, замените `main` на имя ветки из pull request):

<https://colab.research.google.com/github/adekaa11/wastewise/blob/main/train/wastewise_colab.ipynb>

Затем меню **Среда выполнения → Сменить среду выполнения → T4 GPU → Сохранить**.

## Шаг 2. Секреты (по желанию, но лучше сделать)
В Colab нажмите значок 🔑 **«Секреты»** слева → **«Добавить новый секрет»**, впишите имя и значение,
включите переключатель **«Доступ к блокноту»**.

| Секрет | Зачем | Где взять |
|---|---|---|
| `SUPABASE_URL` | скачать ваши фото «Модель ошиблась» | `https://<id проекта>.supabase.co` (шаг 0) |
| `SUPABASE_SERVICE_KEY` | то же | секретный ключ из шага 0 |
| `KAGGLE_USERNAME`, `KAGGLE_KEY` | ~940 фото батареек из Garbage Dataset | kaggle.com → Settings → API → **Create New Token**: в скачанном `kaggle.json` поля `username` и `key` |

Без секретов Supabase модель учится только на открытых датасетах. Без Kaggle батареек будет очень мало —
модель будет узнавать в основном электронику (телефоны, пульты, лампочки). Если добавили секреты Kaggle,
в ячейке 3а поставьте `USE_GARBAGE_DATASET = True`.

## Шаг 3. Запустить ячейки по порядку
Нажимайте ▶ слева от каждой ячейки и ждите, пока она закончится (слева появится зелёная галочка).

| Ячейка | Что делает | Время |
|---|---|---|
| 1 | проверяет видеокарту — должна быть строка `Tesla T4` | секунды |
| 2 | скачивает код проекта | ~1 мин |
| 3 | скачивает открытые датасеты: TrashNet, RealWaste, TACO, Open Images (и Garbage Dataset, если включили) | ~10–15 мин |
| 4 | скачивает ваши фото из Supabase | ~1 мин |
| 5 | собирает датасет и печатает таблицу: сколько фото каждого класса в train / val / test | ~3 мин |
| 6 | **обучение** | ~1 час |
| 7 | сравнивает старую и новую модель | ~2 мин |
| 8 | скачивает новую модель на ваш компьютер | секунды |

После ячейки 5 посмотрите на таблицу: если пишет `⚠️ нет ни одного фото класса …`, перезапустите ячейку
со скачиванием источника этого класса (иногда Flickr или Kaggle отвечают не с первого раза).

## Шаг 4. Прочитать результат сравнения (ячейка 7)
Обе модели отвечают на **одни и те же** тестовые фото — их не было в обучении. Пример:

```
| Класс                   | Фото | Старая         | Новая          | Разница   |
| Стекло                  |  250 | 88.0% (220/250)| 93.2% (233/250)| +5.2 п.п. |
| Батарейки и электроника |  180 | —              | 90.6% (163/180)|           |
...
Старые классы по источникам фото (белый фон → настоящие фото):
| trashnet  | 253 | 95.3% | 94.9% |
| realwaste | 420 | 61.0% | 86.4% |
✅ На старых классах новая модель не хуже старой — её можно ставить на сайт.
```

- **«—»** у старой модели — этого класса она не знает.
- Таблица «по источникам» показывает главное: насколько модель лучше на **настоящих** фото (realwaste, taco, ours),
  а не только на белом фоне (trashnet).
- **✅** — новая модель на каждом из 4 старых классов не хуже старой. **❌** — хуже хотя бы на одном: не ставьте её на сайт,
  смотрите раздел «Если стало хуже».

## Шаг 5. Поставить модель на сайт
1. Ячейка 8 скачает `new_best.pt` (и `compare.json` — результат сравнения, сохраните его).
2. Переименуйте `new_best.pt` в **`best.pt`**.
3. GitHub → репозиторий → папка **`assets`** → **Add file → Upload files** → перетащите `best.pt`
   → внизу **Commit changes** (в `main`). Файл заменит старую модель; старая останется в истории GitHub.
4. Streamlit Cloud сам перезапустит сайт (или **⋮ → Reboot app**). На странице «Распознать отходы» появится
   «Модель знает 7 типов».

Вернуть старую модель: GitHub → `assets/best.pt` → **History** → предыдущая версия → скачать и загрузить обратно.

## Если стало хуже (❌)
- **Больше эпох:** в ячейке 6 поставьте `--epochs 50`.
- **Как у старой модели:** `--imgsz 512` (старая училась на 512 px) — точнее на мелких предметах, но учится ~2,5 раза дольше.
- **Больше своих фото того класса, где просело,** — особенно настоящих, с телефона.
- **Посмотрите строку «Чаще всего новая модель путает»** — она подскажет, каких фото не хватает.
- Допуск в процентных пунктах можно задать явно (`--tolerance 1`), но лучше этого не делать: правило — «не хуже».

## Если что-то пошло не так
- **`CUDA out of memory`** — в ячейке 6 добавьте `--batch 32`.
- **Colab отключился** — данные пропадают вместе с виртуальной машиной: запускайте снова с ячейки 2.
- **Ячейка 4 пишет «Секретов Supabase нет»** — проверьте имена секретов и переключатель «Доступ к блокноту».
- **Без видеокарты** обучение займёт много часов — вернитесь к шагу 1.

## Лицензии датасетов
Ссылки и лицензии проверены по страницам авторов (октябрь 2026). Автор и ссылка каждого фото — в `ATTRIBUTION.csv`
собранного датасета.

| Источник | Что даёт | Лицензия |
|---|---|---|
| [TrashNet](https://github.com/garythung/trashnet) (Thung & Yang, 2016) | 2527 фото на белом фоне: стекло, металл, бумага, картон, пластик, прочее | MIT |
| [RealWaste](https://github.com/sam-single/realwaste) (Single, Iranmanesh, Raad, 2023) | 4752 фото настоящего мусора на полигоне, в т. ч. органика | **CC BY-NC-SA 4.0** у авторов (на [UCI](https://archive.ics.uci.edu/dataset/908/realwaste) указана CC BY 4.0 — берём более строгую) |
| [TACO](http://tacodataset.org) (Proença & Simões, 2020) | вырезки мусора «в природе»: улицы, пляжи, лес | разметка CC BY 4.0; у фото свои лицензии (Flickr CC, ODbL OpenLitterMap) |
| [Open Images](https://storage.googleapis.com/openimages/web/index.html) (Google) | электроника: телефоны, ноутбуки, пульты, лампочки… | разметка CC BY 4.0; фото помечены как CC BY 2.0 |
| [Garbage Dataset v2](https://www.kaggle.com/datasets/sumn2u/garbage-classification-v2) (Kunwar, 2026), по желанию | батарейки, органика | открытая, заявлена автором; часть фото собрана из интернета |
| Ваши фото «Модель ошиблась» | настоящие фото с телефонов | ваши |

Из-за RealWaste (NC — «некоммерческое») и фото с разными лицензиями модель, обученная на этом наборе, —
**только для учебного некоммерческого использования**. Для школьного проекта это подходит.

## Без Colab (компьютер с видеокартой NVIDIA)
```bash
pip install -r requirements.txt
python -m train.taco --out raw/taco
python -m train.openimages --out raw/openimages --per-class 200
# TrashNet и RealWaste — как в ячейке 3 ноутбука; свои фото: SUPABASE_URL=… SUPABASE_SERVICE_KEY=… python -m train.feedback_export
python -m train.dataset --raw raw --out datasets/wastewise
python -m train.train --data datasets/wastewise --base assets/best.pt
python -m train.evaluate --test datasets/wastewise/test --old assets/best.pt --new models/new_best.pt
```
