# ♻️ WasteWise — сортировка отходов с помощью ИИ

Веб-приложение: фотографируешь мусор, нейросеть определяет тип отхода (стекло, металл, бумага, пластик) и показывает, куда его выбросить и что НЕ принимают. Есть викторина, баллы и рейтинг школ.

Автор проекта: Адильжан Кадыргажы (Астана) — [Telegram](https://t.me/crybaby_c) · [Instagram](https://www.instagram.com/_kadyrgazhy_a)

## Что нового в версии 2
| Было | Стало |
|---|---|
| Только картинка с английской меткой | Ответ на русском, уверенность в %, советы «куда выбросить» и «что не принимают», интересный факт |
| Только загрузка файла | Загрузка + съёмка камерой телефона |
| Если модель не уверена — молчит | Предупреждение и 2-й вариант, если уверенность ниже 60% |
| Модель грузится при каждом клике | Грузится один раз (быстро) |
| Пароли: sha256 без «соли» | PBKDF2 + соль (как в нормальных сайтах) |
| Викторина только с ключом OpenAI, модель gpt-3.5 | 12 готовых вопросов работают без интернета + ИИ-режим (gpt-4o-mini, надёжный JSON) |
| Без мотивации | Баллы, рейтинг участников и школ |
| Ошибки модели теряются | Кнопка «Модель ошиблась» → фото сохраняется в `data/feedback/` для дообучения |
| 150 лишних библиотек в requirements | 8 нужных, готово к выкладке на Streamlit Cloud |

## Структура
```
app.py              ← весь интерфейс (страницы сайта)
core/content.py     ← тексты: советы по утилизации, вопросы викторины, баллы
core/model.py       ← нейросеть: загрузка и распознавание
core/db.py          ← база данных: пользователи, баллы, история
core/quiz.py        ← викторина (готовые вопросы + ИИ)
assets/             ← модель best.pt, логотип, картинка
samples/            ← тестовые фото
train/              ← скрипт переобучения на YOLO26
data/               ← создаётся сам: база app.db и фото-исправления (в git не попадает)
```

## Запуск на компьютере (Windows)
```bash
cd "waste project v2"
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```
Откроется http://localhost:8501. Для ИИ-викторины скопируйте `.env.example` в `.env` и вставьте ключ OpenAI.

## Выложить в интернет (получить ссылку)
1. Создать репозиторий на GitHub и загрузить туда эту папку (`.env` не загрузится — так и надо).
2. Зайти на share.streamlit.io → New app → выбрать репозиторий → файл `app.py`.
3. В настройках приложения → Secrets добавить: `OPENAI_API_KEY = "ваш ключ"`.

⚠️ На бесплатном Streamlit Cloud база `data/app.db` стирается при перезапуске. Для постоянного рейтинга позже нужна внешняя база (например, Supabase).

## Ограничения (честно)
- Модель знает только 4 класса, обучена на ~450 фото (top-1 точность 91,8% на тестовой выборке).
- Это классификация: один предмет на фото. Если на фото куча разного мусора — ответ будет неточным.
- Ultralytics распространяется под лицензией AGPL-3.0: для коммерческого закрытого продукта нужна платная лицензия.
